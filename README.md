# مسار التميز — Masar Al-Tamayuz

ثيم ووردبريس عربي (RTL) أنيق للمتاجر والخدمات والمدونات. الإصدار 2.0.

## التركيب
مظهر ← قوالب ← إضافة ← رفع قالب ← اختر ملف ZIP ← تفعيل.
بعدها: مظهر ← تخصيص ← **✨ إعدادات مسار التميز**.

## القوالب الجاهزة
| القالب | الفكرة | يُناسب |
|---|---|---|
| `fashion` أزياء وموضة | هيرو بصورة كبيرة، تصنيفات دائرية، "وصل حديثاً"، بانرات، آراء، إنستجرام | ملابس، أحذية، شنط |
| `luxe` فخامة داكنة | خلفية داكنة وذهبي، شريط مميزات، 3 بانرات، منتجات مختارة، علامات، مجلة | إكسسوارات، ساعات، عطور |
| `services` خدمات وتصميم | هيرو بقوس، خدمات، مشاريع، مؤسِّس، خطوات، FAQ | تصميم داخلي، استشارات، عيادات |
| `decor` ديكور منزلي | كروت أقسام، بانر مجموعة، منتجات، إحصائيات | ديكور، شموع، مفروشات |

**طريقتان للاستخدام**
1. للرئيسية: تخصيص ← القالب الرئيسي للموقع.
2. لأي صفحة: إعدادات الصفحة ← القالب ← اختر `مسار — رئيسية: ...`.

**قوالب داخلية:** من نحن، تواصل معنا، الأسئلة الشائعة، ومساحة حرة (للسكاشن بالشورت كود).

## مكتبة السكاشن (19 سكشن)
استخدمها في أي صفحة بالشورت كود: `[masar_section name="faq" title="أسئلة شائعة"]`

| الاسم | الوصف | المتغيرات |
|---|---|---|
| `hero` | الهيرو | style: center / split / arch / full |
| `features` | شريط مميزات (شحن، دفع...) | variant: soft / dark |
| `cats-circles` | تصنيفات دائرية | يسحب تصنيفات WooCommerce تلقائياً |
| `cats-cards` | تصنيفات ككروت بسهم | — |
| `products` | منتجات أو مقالات | variant: grid / side، count |
| `promo-banners` | 2 أو 3 بانرات ترويجية | tone: dark / mocha / sand |
| `feature-banner` | بانر مجموعة كبير | — |
| `testimonials` | آراء العملاء | — |
| `gallery` | إنستجرام أو معرض مشاريع | variant: insta / projects |
| `newsletter` | اشتراك بالنشرة | variant: band / inline |
| `brands` | شريط علامات | — |
| `services` | كروت خدمات | — |
| `process` | خطوات العمل | — |
| `about` | من نحن / المؤسس | — |
| `stats` | أرقام وإحصائيات | — |
| `faq` | أسئلة شائعة | — |
| `cta` | دعوة للتواصل | — |
| `journal` | أحدث المقالات | variant: light / dark |
| `contact` | وسائل التواصل | — |

الشورت كود يقبل: `name` `title` `subtitle` `count` `variant`. للتحكم الكامل بالمحتوى (قوائم العناصر) عدّل `inc/presets.php` أو استخدم الفلتر `masar_preset_sections` من child theme.

## الهيدر (4 أنماط)
`split` كلاسيك · `center` لوجو بالمنتصف · `luxe` قائمة/لوجو/أيقونات · `minimal` شفاف.
خيارات: تثبيت، شفاف فوق الهيرو، بحث، حسابي، وضع ليلي، زر CTA، شريط علوي بروابط.

## الفوتر (4 أنماط)
`columns` أعمدة · `centered` مركّز · `dark` داكن · `minimal` سطر واحد.
خيارات: شريط النشرة، نبذة، التواصل، السوشيال، شعارات الدفع، حقوق النشر.

## ألوان وخطوط
11 لوحة ألوان (بيج، تيراكوتا، ذهبي داكن، زيتوني، خريفي، وردي...)، ألوان مخصصة، 9 خطوط عربية، وضع ليلي.

## ملاحظات
- النصوص والصور الافتراضية للتجربة؛ الصور تتحول لأماكن صور أنيقة لحد ما تضيف صورك.
- النشرة البريدية تحتاج رابط معالجة (Mailchimp / Formspree) من تخصيص ← الفوتر.
- الأيقونات إيموجي لتفادي الاعتماد على مكتبات خارجية.
