Arabic-first (RTL) WordPress theme for stores, service businesses and blogs, with ready-made homepage templates and a reusable section library.

== Description ==

مسار التميز ثيم ووردبريس عربي (RTL) أنيق للمتاجر والخدمات والمدونات.

* 4 homepage templates: fashion, dark luxe, services and interior design, home decor.
* 4 inner page templates: about, contact, FAQ and a free canvas page.
* 19 reusable sections, usable anywhere with the `[masar_section name="faq"]` shortcode.
* 4 header styles and 4 footer styles, selectable from the Customizer.
* 11 colour palettes, custom colours, dark mode toggle.
* "Masar Studio" admin page: show/hide, reorder and edit homepage sections without code.
* One-click demo content import (and safe removal).
* Local Arabic fonts (no external font requests), SVG icon set.
* Floating WhatsApp button and WooCommerce support.

== Installation ==

1. Appearance, Themes, Add New, Upload Theme, choose the ZIP file, then Activate.
2. Appearance, Customize, "إعدادات مسار التميز" to choose the template, colours, fonts, header and footer.
3. Optional: Appearance, "استوديو مسار" to edit sections and import demo content.

== Frequently Asked Questions ==

= Does it need WooCommerce? =

No. Product sections show sample cards until WooCommerce is active.

= Is the theme translation ready? =

Not yet. The interface text is written directly in Arabic. Only a few strings go through the WordPress translation functions.
